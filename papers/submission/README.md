# Wave 2 submission drafts

Each Wave 2 manuscript directory has a `submission/` folder. Its files are drafts for the repository owner's approval before any upload, announcement or correspondence. The [Wave 2 contract](../WAVE2-CONTRACT.md) defines the evidence labels and standard AI-use disclosure. The [policy review](POLICIES.md) records venue requirements, the proposed release order and the decisions reserved for the owner.

- `abstract.txt` contains the plain-text abstract for submission forms.
- `alphaxiv.md` collects the proposed byline, title, abstract, classifications, disclosure, and pinned source and verification links.
- `announcement.md` contains drafts for a short public post and a mathematics forum announcement.
- `summary.md` gives a one-paragraph mathematical summary.
- `reviewer-inquiry.md` contains draft requests for specialist feedback on specific mathematical questions.
- `reviewer-packet.md` presents the claims and proofs or proof sketches, external inputs, evidence labels, reproduction links and points for specialist review.

The manuscript's `VERIFICATION.md` gives the evidence for each result and its `LEDGER.md` records the prior-art search. Cross-model review is not peer review. Independent human specialist review is outstanding.

## What is completely kernel-verified

- **Theorem A** (unsigned dichotomy, every positive order, every finite prime support, any overlap with the radix). The mathlib-only statement `PaperII.UnsignedClassification` in `Statements.lean` is proved in `Check.lean` as `PaperII.unsignedClassification` from `unsigned_discrepancy_limit` and `unsigned_finite_support_normal`. Its definitions (smooth indices `m = i+1`, half-open frequencies `visits`, `Normal`, `discrepancy`) use only mathlib. The empirical definitions agree with the library's by unfolding, and the zero summand of the polynomial library is removed in `polynomialValue_eq`.
- **Theorem B**, equivalence part (`PaperII.polynomialClassification`, including order `s = 0`), and the failing-case lower bound and nonnormality on every mask in the library definitions (`rational_boundary`). The kernel gives an integer `L` coprime to `b`; the identification `L = D_0` in the paper is a written argument.
- **Theorem C(i)** for rational numerators `P_i(0) != 0`: `PaperII.jointPolynomial` in `Check.lean` (mathlib-only statement, new in this version). The unsigned case is also `LocalizedJointStatements.DistinctOrders`, proved as `distinct_orders_checked`.
- **Theorem C(ii),(iii), D(ii),(iii), E, F, 4.1, A.1, Example A.2, Example 5.1, Proposition 6.3 and Remark 6.2** as Lean statements in the library's own definitions (`maskedValue`, `radixDiscrepancy`, `JointUniform`, `NormalIn`). These definitions were read against the paper's displayed series. They are not re-stated in mathlib-only form here. `maskedValue b S keep P t` is `series b (weights ...)` with `weights S keep P t m = P(m)/m^t` on retained smooth `m` (including the vanishing `m = 0` term) and `JointUniform` is the box-frequency statement over positions `0..N-1` of `Int.fract (b^n * x_i)`.
- Axiom audit: `AuditDeclarations.lean` checks 41 declarations; all depend only on `propext`, `Classical.choice`, `Quot.sound`. `Check.lean` does the same for its three theorems. Both were run (25 November 2026) against the oleans of a complete build of `e4809cf` made by the coordinator in WSL, used read-only through `LEAN_PATH`; no build was run in this worktree.

Not kernel-verified, and labelled accordingly in the paper: Lemma 2.1 (paper proof, external input), Lemma 3.1 (the valuation argument), Theorem D(i) (the counting step from the window count to the density `g`), Corollary 6.1 (gap bound and grouping), Propositions 7.2 and 10.1, Example 7.1, the outline of Theorem F, the identification `L = D_0`, and all literature comparisons.

## External analytic dependencies

- Vandehey, *Differencing methods for Korobov-type exponential sums*, J. Anal. Math. 138 (2019), 405-439, Corollary 1.2 (numbering of arXiv:1606.07911, checked on the arXiv text on 25 November 2026): for a fixed finite prime set `P`, `m` supported on `P`, `gcd(a,m) = gcd(m,b) = 1`, `N >= m^epsilon`, the sum `|sum_{n<=N} e(a b^n / m)|` is at most `C N m^(-delta) (1 + log m)`. Used in Lemma 2.1 only. The library contains an independent proof (`fixed_support_orbit_estimate`, `SmoothOrbit.lean#L207`), so none of the kernel-verified theorems depends on the citation.
- Weyl's criterion (one and several variables), Poincare recurrence for a rotation, and elementary facts on eventual periodicity in a finite monoid appear in written proofs only as textbook inputs.

## Reproduce

From a repository checkout at `e4809cf` (or the release containing this directory) with the pinned Lean toolchain:

```sh
lake build NormalityChecker.LocalizedJoint NormalityChecker.LocalizedCertificateModulus \
  NormalityChecker.LocalizedSignedAxis NormalityChecker.LocalizedDiscrepancy NormalityChecker.MaskPeriods \
  NormalityChecker.MaskDensity NormalityChecker.MaskQuotients NormalityChecker.MaskThirds \
  NormalityChecker.MaskWindows NormalityChecker.HigherOrderPhase NormalityChecker.JointPersistent \
  NormalityChecker.SmoothOrbit
lake env lean papers/02-localized-normality-v2/AuditDeclarations.lean
papers/02-localized-normality-v2/check.sh
python scripts/localized_certificate.py 4 3 3 2 3 11 --order 1    # Theorem E example, precision 3
python scripts/localized_certificate.py 32 31 3 2 31               # Section 10 example: bounds 1/2, 31/960, 0
wsl -d Ubuntu -- bash papers/wsl-build.sh 02-localized-normality-v2
```

What was run for this version: the TeX build (no undefined references or citations); `Check.lean` and `AuditDeclarations.lean` as described above, in a scratch directory with `LEAN_PATH` set to the oleans of `~/wave2-verify/repo` (checkout `e4809cf`) and its `.lake/packages`; `scripts/localized_certificate.py` for `b = 4, p = 3`, supports `{2,3,11}`, orders 1 and 2, precisions 1-3 (outputs quoted in Section 8 of the paper: order one bounds 1/2, 3/8, 3/11, order two bound 0), and for `b = 32, p = 31` (bounds 1/2, 31/960, normality certified at precision 3). `check.sh` itself was not run through `lake` in this worktree because the worktree has no build; its steps were replicated by compiling `Statements.lean` to an olean and running `Check.lean`.

Pins in this directory: the paper links Lean at `e4809cf`. `Statements.lean`, `Check.lean`, `AuditDeclarations.lean` and `check.sh` are new files in this directory and cannot be linked at `e4809cf`; the owner should pin them to the release commit.

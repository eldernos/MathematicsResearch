## Indexes

- [Curated result index](results.md): every major result with a permanent identifier, statement, scope, Lean declaration, proof, paper and kind of evidence. Generated from the [registry](registry/SCHEMA.md).

## Maintaining the derived pages

`docs/results.md`, `docs/theorems.md`, `docs/figures.md`, the declaration manifest, the manuscript and result-family tables of the README, and the figure blocks of `docs/survey.md` are generated. `papers/BIBLIOGRAPHY.bib` is generated by `python3 scripts/site.py bib`. The declaration directory at the end of the README is still generated into the README by `scripts/readme_theorems.lean`. After changing Lean statements, run `lake build`, then `NORMALITY_UPDATE_THEOREM_INDEX=1 lake env lean scripts/readme_theorems.lean`, which also runs `python3 scripts/portal.py build`. After editing the registry, run `python3 scripts/portal.py build`. After editing a figure generator, run `python3 scripts/figures/build.py --pdf`. `python3 scripts/portal.py check` verifies all of it and runs as part of `scripts/verify.sh`.
